# Dirección visual de AirKids

- Azul noche (#263b70), celeste (#e8effa), amarillo cálido (#ffdf7d) y fondo marfil.
- Manrope para títulos; DM Sans para lectura. Fuentes locales mediante Fontsource.
- Portada de ambiente generada con IA, identificada como imagen de ambiente; no representa un artículo disponible.
- Fotos originales de producto completas, con object-fit: contain, sin ampliar por encima de su resolución.
- Catálogo de dos columnas en celular, tres en escritorio. Acción visible para abrir el detalle.
- Conservar contraste, foco de teclado, etiquetas y soporte de movimiento reducido.
